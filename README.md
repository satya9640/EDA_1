🌸 Iris Dataset Analysis & Classification Project
*Project Overview
This project focuses on Exploratory Data Analysis (EDA) and classification modeling using the famous Iris dataset.
The objective is to analyze the dataset, understand the relationships between features, and build a machine learning model to classify iris flower species accurately.

*This project demonstrates fundamental concepts in:
->Data Cleaning
->Data Visualization
->Statistical Analysis
->Machine Learning Classification

*About the Dataset
->The dataset used in this project is the Iris dataset, originally introduced by Ronald A. Fisher.
->It contains 150 observations of iris flowers from three species:
    Setosa
    Versicolor
    Virginica
    
*Each observation includes the following features:
    Sepal Length
    Sepal Width
    Petal Length
    Petal Width

*Species (Target Variable)

🎯 Problem Statement

 ->To classify iris flowers into one of the three species based on their physical measurements using data analysis and machine learning techniques.
